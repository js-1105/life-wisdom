## 操作

| 按鍵 | 功能 |
|---|---|
| ← → | 翻頁 |
| O | 章節總覽（點任一頁直接跳過去） |
| G | 輸入頁碼跳頁 |
| F | 全螢幕 |
| Home / End | 第一頁 / 最後一頁 |
| Ctrl+C | 清掉滑鼠所指那一組的投稿（不跳確認） |
| Shift+C | 下課後全部清空（先下載 CSV、雲端封存，再確認） |

## 課堂投稿

各組手機掃 QR 進入 `submit.html`（六組分區討論）或 `ask.html`（小組共識），
即時顯示在投影幕上。房號設定見 `fbconfig.js` 的 `FB_ROOM`，每學期換一個即可清空重來。
