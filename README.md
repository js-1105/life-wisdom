## 操作

| 按鍵 | 功能 |
|---|---|
| ← → | 翻頁 |
| O | 章節總覽（點任一頁直接跳過去） |
| G | 輸入頁碼跳頁 |
| F | 全螢幕 |
| Home / End | 第一頁 / 最後一頁 |
| Shift+C | 清空當前投稿頁的內容 |
| Shift+E | 匯出投稿 CSV 並清空 |

## 課堂投稿

各組手機掃 QR 進入 `submit.html`（六組分區討論）或 `ask.html`（小組共識），
即時顯示在投影幕上。房號設定見 `fbconfig.js` 的 `FB_ROOM`，每學期換一個即可清空重來。
